=============================
keyboard-show
=============================

--------------------------------------------------------------
Shows Android virtual keyboard
--------------------------------------------------------------
:Version: keyboard-show |version|
:Manual section: 1


Synopsis
========

keyboard-show *[options]*


Description
===========

Shows Android virtual keyboard.


Application options
=====================

-m                   Launch mode.
                     It can be 'sdotool'.

-h                   Display help.
-c                   Enable color output
-v                   Enable verbose output
